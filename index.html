03 / What I work with

The tools behind the experience.

Technical skills applied to the everyday problems of building and maintaining Roblox games.

Typed Luau

Strict mode with --!strict, explicit type aliases, and shared interfaces to catch mistakes earlier and make modules easier to understand.

Player data & persistence

ProfileStore and DataStore workflows, session locking, and structured player profiles, with attention to save reliability and data consistency.

Game architecture

State machines, round managers, lobbies, and modular controllers that separate responsibilities and support new features.

Networking & validation

Server-side validation, rate limiting, buffer packing, and delta updates to manage replication and reduce unnecessary traffic.

UI scripting & animation

Reactive UI with Fusion, TweenService animations, camera controls, and interfaces that adapt to different screens.

Performance & cleanup

Microprofiler analysis, connection cleanup with Janitor or Maid patterns, and attention to memory usage and frame times.

Clear communication

Scope, progress, and handoff discussed through Discord.

Server-first decisions

Validate player requests before changing game state.

Code built to continue

Modular structure and types for easier future changes.
